# 🌍 LinguaVoice AI – Multilingual Voice Translator

**Every Voice Has a Meaning!**

LinguaVoice AI is a multilingual voice translation web application built using HTML, CSS, and JavaScript. Translate text between languages, convert speech into text, and listen to translated messages.

## 🚀 Live Demo

👉 **[Click Here to Open LinguaVoice AI](https://dhilip-2007.github.io/linguavoice-ai/)**

## 💻 GitHub Repository

🔗 [View Source Code on GitHub](https://github.com/dhilip-2007/linguavoice-ai)

## ✨ Features

- 🌐 Multilingual translation across 12 languages.
- 🎙️ Speech recognition using microphone input.
- 🔊 Text-to-speech playback for translated messages.
- 🔄 Swap source and target languages.
- 📋 Copy translated text to the clipboard.
- 🧹 Clear input and translation results.
- 📱 Responsive design for desktop and mobile.
- 🎨 Modern interface with gradients and interactive controls.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- MyMemory Translation API
- Web Speech API

## 🌎 Supported Languages

English, Tamil, Hindi, Telugu, Malayalam, Kannada, French, Spanish, German, Japanese, Chinese, and Arabic.

*Speech recognition and voice availability depend on browser and device support.*

## 🚀 Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/dhilip-2007/linguavoice-ai.git
```

**2. Open the project folder**

```bash
cd linguavoice-ai
```

**3. Open in VS Code**

```bash
code .
```

**4. Start the application**

- Install the Live Server extension in VS Code.
- Open `index.html`.
- Right-click and select **Open with Live Server**.

## 📖 How to Use

1. Select the source language.
2. Select the target language.
3. Enter text or click the microphone button.
4. Click **Translate now**.
5. View the translated text.
6. Click **Listen** to hear the translation.
7. Click **Copy** to copy the result.
