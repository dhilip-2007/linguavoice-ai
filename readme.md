# 🌍 LinguaVoice AI – Multilingual Voice Translator

**LinguaVoice AI** is a web-based multilingual translation application that helps users translate text between different languages, convert speech into text, and listen to translated messages using voice playback.

The project combines **Text and Speech Analysis** concepts with a modern, responsive user interface.

## ✨ Features

- 🌐 **Multilingual Translation** – Translate text between 12 supported languages.
- 🎙️ **Speech Recognition** – Use your microphone to convert spoken words into text.
- 🔊 **Text-to-Speech** – Listen to translated text using browser speech synthesis.
- 🔄 **Language Switching** – Swap source and target languages instantly.
- 📋 **Copy Translation** – Copy translated text to your clipboard.
- 🧹 **Clear Text** – Clear the input and translation areas.
- 📱 **Responsive Design** – Works across desktop, tablet, and mobile screens.
- 🎨 **Modern UI** – Clean interface with gradients, language selectors, and interactive controls.

## 🛠️ Technologies Used

- **HTML5** – Application structure
- **CSS3** – Styling, layouts, gradients, and responsive design
- **JavaScript** – Translation logic and interactive functionality
- **MyMemory Translation API** – Online text translation service
- **Web Speech API** – Browser-based speech recognition and voice playback

## 🌎 Supported Languages

The application includes these 12 languages:

1. English
2. Tamil
3. Hindi
4. Telugu
5. Malayalam
6. Kannada
7. French
8. Spanish
9. German

## 🚀 How to Run the Project

### Step 1: Download or clone the repository

```bash
git clone https://github.com/dhilip-2007/linguavoice-ai.git
```

### Step 2: Open the project folder

```bash
cd linguavoice-ai
```

Open this folder in Visual Studio Code.

### Step 3: Run the application

1. Install the **Live Server** extension in VS Code.
2. Open `index.html`.
3. Right-click the file.
4. Select **Open with Live Server**.
5. Your application will open in your browser.

No Node.js installation is required for this frontend version.

## 📖 How to Use

1. Select the source language.
2. Select the target language.
3. Enter text or click **Speak** and use your microphone.
4. Click **Translate now**.
5. View the translated result.
6. Click **Listen** to hear the translation.
7. Use **Copy** to copy the result or **Clear** to start again.

## ⚠️ Limitations

- An internet connection is required for online translation.
- The public translation service may impose usage limits or become unavailable.
- Speech recognition depends on browser support and microphone permissions.
- Text-to-speech voices depend on the voices installed or available in the browser.
- This version does not include a custom AI model or backend server.
